# Stage 2 Entry: education

## Target

- 权威目标字段来自单独的 `## Stage 2 Runtime Target` section。
- 本节点目标字段：device_explained（设备说明）。
- 默认措辞只用于参考；如果 Runtime Target 指定其他字段，以 Runtime Target 为准。

## Natural Continuation

接上上一句 assistant，像继续同一口气说下去。
可以用「那再了解一下设备使用这块」自然转入宣教落实。
不要总结程控。

## Hard Rules

- 本句必须问出 Stage 2 Runtime Target 指定的字段。
- Runtime Target 指定字段时，本句必须带问号。
- 只问 Runtime Target 指定的一个字段；不要顺手合并其他节点或其他字段。
- 禁止只说「接下来了解宣教情况」这类铺垫。

## Examples

Bad: 好的，那接下来了解一下宣教的情况。
Good: 那当时医生有没有跟您说明设备的使用方法？
