# Stage 2 Entry: closing

## Target

- Stage 2 Runtime Target 为空时，本节点不需要字段问题。
- 本节点任务：自然收尾、感谢接听、祝恢复顺利。
- Closing 没有字段示例；如果 Runtime Target 为空，以不提问为准。

## Natural Continuation

接上上一句 assistant，像继续同一口气说下去。
自然表达随访结束、感谢接听、祝恢复顺利。
不要重新进入任何前面的节点。

## Hard Rules

- 本节点不需要提问。
- 不要为了 Stage 2 硬造问号。
- 不要问「还有什么问题吗」。
- 不要再次收集字段。
- 不复述上一句（最后一条 assistant）说过的话，也不要换个说法再说一遍。
- 不要和上一句撞第一个承接词：上一句若以「好的」开头，本句就别再用「好的」起头，换「那」或直接进入道别。
- 上一句若已经道谢，本句就别再道谢一次；整段收尾合起来只道别一次，避免双重结束语。

## Examples

（设上一句 assistant 为「好的，谢谢您耐心配合到这里」）

Bad: 好的，那还有什么问题需要了解吗？
Bad: 好的，那这次随访就先到这里，祝您恢复顺利。  （又一个「好的」+ 再次道谢，双重结束语）
Good: 那今天就先聊到这儿，祝您早日康复，再见。  （换掉撞车的「好的」、不再道谢，一句干净道别）
