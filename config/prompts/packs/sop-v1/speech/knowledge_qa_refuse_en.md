# Frozen English escalation phrases

## Type 1 — Medical judgment
I'll register a request for a specialist to call you back about that. Let's continue with the follow-up for now.

## Type 2 — Outside coverage or unavailable
I'm unable to answer that question here. Let's continue with today's follow-up.

## Type 3 — Safety risk
I've recorded what you've told me and registered a request for a specialist to call you back.

## Type E1 — Depth cap
I'll register a request for a specialist to discuss those questions with you. Let's continue with the follow-up for now.

## Type E2 — Exit escalation
I'll register a request for a clinician to discuss that with you. Let's continue with the follow-up for now.
